## 📖 Overview
This site combines a personal academic portfolio with a functional task management tool. It was built using semantic HTML5, external CSS (Flexbox & Grid), and vanilla JavaScript — no frameworks or libraries.

## ✨ Features
- **Home** — Landing page with intro and quick bio
- **About Me** — Full bio, skills list, academic background
- **Projects** — Showcase of 3 real projects (Caerus, Amanda AI, FreshWave) with tech stacks
- **Academic Planner** — Add, complete, delete, and filter tasks; persists via `localStorage`
- **Contact** — Form with client-side validation (empty-field checks, email format, phone digits-only)
- Fully responsive layout with a mobile hamburger nav
- Smooth CSS animations and hover transitions

## 🛠 Tech Stack
- HTML5 (semantic elements)
- CSS3 (Flexbox, Grid, media queries, keyframe animations)
- Vanilla JavaScript (DOM manipulation, event handling, localStorage)
